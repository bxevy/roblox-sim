Hand-made creature models go here as .rbxm files, named after the species id:
  Sproutling.rbxm      used for every stage
  Sproutling_2.rbxm    optional: a different model for the Mature stage
  Sproutling_3.rbxm    optional: a different model for the Ascended stage
See docs/ASSETS.md ("Creature models") for how to make one from an FBX.
