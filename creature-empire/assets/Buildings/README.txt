Hand-made building models go here as .rbxm files, named after the building type:
EmpireCore, MoonpetalFarm, ResourceSilo, TradingPost, Habitat, CrystalMine,
CrystalSmelter, EssenceCondenser, Hatchery, EvolutionChamber, ResearchStation,
CourierPost, ExpeditionPortal. Add _2, _3... for a different model per level.
See docs/ASSETS.md ("Building and world models").
